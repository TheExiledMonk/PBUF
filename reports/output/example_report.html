7. Methodology Notes

Methodology Notes

  • χ² values are absolute unless explicitly labeled as "reduced χ²".
  • AIC and BIC penalize models with more free parameters; lower is preferred.
  • ΔAIC and ΔBIC are reported as (MODEL_B - MODEL_A); positive values indicate stronger statistical support for MODEL_A.
  • SN = luminosity distance vs redshift (Pantheon+ style).
    BAO = acoustic standard ruler constraints from galaxy clustering.
    CC = cosmic chronometers, differential ages → H(z).
    RSD = fσ₈(z) growth constraints from redshift-space distortions.
    CMB = Planck 2018 compressed distance priors (R, ℓA, θ*).
  • All plots were generated directly from the cosmology module for each model (ΛCDM and PBUF) using the same test parameters that were used to compute χ².
